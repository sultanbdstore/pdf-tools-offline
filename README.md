# 📄 অফলাইন পিডিএফ মার্জার ও স্প্লিটার

PDF জোড়া লাগান, আলাদা করুন, পেজ সাজান — **কোনো ফাইল আপলোড না করে**। সব কাজ আপনার ফোন/কম্পিউটারের ব্রাউজারেই হয়; একবার খুললে ইন্টারনেট ছাড়াও চলে। ফোনে ইনস্টল করা যায় (PWA)।

**লাইভ লিংক (Pages চালু করলে):** `https://sultanbdstore.github.io/pdf-tools-offline/`

## ফিচার
| ট্যাব | কী করা যায় |
|---|---|
| 🔗 **জোড়া লাগান** | একাধিক PDF ও ছবি (JPG/PNG/WebP) একসাথে; ক্রম বদল (▲▼); প্রতিটি ফাইল থেকে শুধু বাছাই করা পেজ (`1-3, 5, 8-`) |
| ✂️ **আলাদা করুন** | পেজের ছোট ছবি দেখে ছুঁয়ে বাছাই (সব/উল্টো/জোড়/বিজোড়/রেঞ্জ); **নির্বাচিতগুলো একটি PDF**, **নির্বাচিত বাদ দিয়ে বাকি**, **প্রতি পেজ আলাদা (ZIP)**, **রেঞ্জ ধরে ভাগ (ZIP)**, **প্রতি N পেজে ভাগ (ZIP)** |
| 🧩 **পেজ সাজান** | সব পেজ কার্ডে: ◀ ▶ সরান, ↻ ঘোরান, ⧉ কপি, 🗑 মুছুন, ➕ ফাঁকা পেজ, উল্টো ক্রম, সব ঘোরান, ↩ ফেরান (undo), নম্বর বসিয়ে সরানো, কম্পিউটারে টেনে এনে সাজানো |
| সবখানে | পেজ নম্বর বসানো (ঐচ্ছিক), ফাইলের নাম ঠিক করা, ডাউনলোড + শেয়ার বোতাম (ফোনে), ডার্ক মোড |

## 🔒 গোপনীয়তা — কীভাবে নিশ্চিত
- কোনো সার্ভার, ট্র্যাকার বা অ্যানালিটিক্স নেই।
- `index.html`-এ কঠোর **Content-Security-Policy** আছে (`connect-src 'self' data: blob:`) — ব্রাউজারই অ্যাপকে বাইরে কোনো ঠিকানায় ডেটা পাঠাতে দেয় না।
- ফাইল শুধু ব্রাউজারের মেমরিতে খোলা হয়; ট্যাব বন্ধ করলে চলে যায়। কিছু `localStorage`-এ সেভ হয় না (শুধু "ছবি কোন মাপে" পছন্দটি)।

## লাইব্রেরি (লোকালি `lib/` ফোল্ডারে — CDN লাগে না)

- [`PDF.js`](https://github.com/mozilla/pdf.js) 6.2.108 (Apache-2.0) — পেজের থাম্বনেইল দেখানো

## GitHub Pages-এ চালু করার ধাপ
1. নতুন রিপো বানান: নাম `pdf-tools-offline`, **Public**।
2. এই ফোল্ডারের **সব ফাইল** (লুকানো `.github` ও `.nojekyll` সহ, এবং `lib/`, `icons/` ফোল্ডার) রিপোর রুটে আপলোড করুন।
3. **Settings → Pages → Source: GitHub Actions** (বা Branch: main / root)।
4. কিছুক্ষণ পর `https://<ইউজারনেম>.github.io/pdf-tools-offline/` খুলবে।
5. ফোনের **Chrome**-এ লিংক খুলে ⋮ মেনু → **Install app / Add to Home screen**।

> `lib/` ফোল্ডার আপলোড না হলে অ্যাপ "লাইব্রেরি পাওয়া যায়নি" দেখাবে। বড় ফাইলগুলো (`pdf.worker.min.mjs` ≈ ১.৩ MB) ওয়েব-আপলোডে সমস্যা করলে GitHub Desktop বা `git push` ব্যবহার করুন।

## ⚠️ সীমাবদ্ধতা (সৎভাবে)
- **পাসওয়ার্ড/এনক্রিপশন দেওয়া PDF** সমর্থিত নয় (আগে পাসওয়ার্ড খুলে সেভ করুন)।
- জোড়া/ভাগ করলে **বুকমার্ক/সূচিপত্র, ফর্মের ঘর, কিছু লিঙ্ক হারাতে পারে** — পেজের লেখা-ছবি-চেহারা ঠিক থাকে।
- পুরো ফাইল মেমরিতে খোলা হয়; শত এমবির বড় PDF-এ পুরোনো ফোন আটকে যেতে পারে। ফাইল বড় হলে আলাদা আলাদা করে কাজ করুন।
- থাম্বনেইলে কিছু বিশেষ ফন্ট/JPEG2000 ছবি ঠিক না-ও দেখাতে পারে; তৈরি PDF-এ মূল পেজই থাকে।
- ছবি থেকে PDF: সব ছবি একই পেজ মাপে (A4 বা ছবির নিজস্ব মাপ) বসে। ফোনের ছবির EXIF ঘোরানো ঠিক করা হয়, তবে JPEG পুনরায় এনকোড হয় (সামান্য মান/সাইজ বদলাতে পারে)।
- পেজ নম্বরে শুধু ইংরেজি সংখ্যা (1, 2, 3…) বসে।
- ডাউনলোড হলে ফোনের Downloads ফোল্ডারে যায়; Chrome অনুমতি চাইলে "Allow" দিন।

## পরীক্ষা
কম্পিউটারের Chrome-এ তৈরি নমুনা PDF (৫, ৩, ১২ পেজ, ল্যান্ডস্কেপ, এনক্রিপ্টেড, নষ্ট ফাইল) ও ছবি (PNG/WebP/EXIF-ঘোরানো JPEG) দিয়ে জোড়া, রেঞ্জ, সব ভাগের ধরন, ZIP, ঘোরানো/মুছা/কপি/ফাঁকা পেজ/undo, অফলাইন রিলোড ও ইনস্টলের শর্ত যাচাই করা হয়েছে। আসল ফোনে ও খুব বড় ফাইলে পরীক্ষা হয়নি।
